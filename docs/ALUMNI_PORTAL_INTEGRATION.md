# 포털 졸업생 네트워크 운영 안내 (2026-11-13 개편)
- 통합 운영: https://portal.k-bigdata.kr/alumni/index.html
- 기존 서비스 https://alumni.k-bigdata.kr **서비스 종료**: 11개 웹페이지는 포털로 이동하며 더 이상 신규 등록·수정을 받지 않습니다.
- 기존 Google Sheets와 포털 DB의 양방향 동기화는 하지 않습니다.
- 포털 Supabase Auth 회원 UUID를 신원, 소유권, 게시자와 상담 발신·수신의 기준으로 사용합니다.
- 최초 포털 회원가입 승인만 사용하며, 동문 프로필·채용공고·동문소식의 별도 관리자 승인은 없습니다.
- 관리자 권한은 매 요청마다 portal_super_admin_allowed()로 확인합니다.
- 운영 테이블: public.alumni_profiles, public.alumni_jobs, public.alumni_news, public.alumni_contact_requests.
- 종전 public.alumni_network_records 449건은 접근이 제한된 **이관 원본 보관소**로 유지합니다. 운영 프로필과 게시물에는 기록을 새로 쓰지 않습니다.
- 연결된 졸업생 기록 42건, 미연결 2건은 보관. 채용 2건, 동문소식 1건, 연락 기록 3건을 신규 테이블에 이관했습니다.
- 회원 프로필 이름·이메일·휴대전화는 public.profiles의 값을 조회합니다.
- 후배 연락 요청은 포털 회원 정보로 전송하며 무료 Quill 에디터와 선택적 학습 역량 제공 동의를 지원합니다.
- 구 Apps Script의 웹 API 및 예약 메일 발송 기능은 소스에서 중지 처리했습니다. 실제 GAS 배포 및 기존 트리거 종료 상태는 운영 배포 검증이 필요합니다.
- 배포 순서: DB 백업 및 마이그레이션 -> API 배포 -> UI 배포 -> 테스트 계정으로 CRUD와 메일 검증 -> 구 서비스 차단 확인.
- 핵심 검증: UUID 권한, 프로필 수정 즉시 반영, 공개/비공개, 게시물 직행 게시, 타인 접근 차단, 수신 동의, 메일 중복 방지, 모바일.
