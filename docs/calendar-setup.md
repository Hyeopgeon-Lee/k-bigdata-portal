# 학과 주요 일정 — 개인 Google Calendar 연동

## 구성

- 포털: https://portal.k-bigdata.kr/schedule.html
- 소스: apps-script/department-calendar.gs / apps-script/appsscript.json
- 프런트 설정: js/schedule-config.js
- 개인 **기본 캘린더**에서 이름이 (학과)로 시작하는 일정만 발췌합니다.
- 8318호·8319호 회의실 예약 캘린더, 일반 개인 일정 및 비공개(Private) 표시한 일정은 제외합니다.
- 공개 필드: 제목·날짜·시각·일정구분만. 일정 설명, 위치, 참석자, 이메일, 첨부파일, Meet URL 등은 반환하지 않습니다.
- 학생은 읽기만 가능하며 일정 등록·수정·삭제는 원래 Google Calendar에서 수행합니다.
- 이 포털은 검색엔진에 노출되지 않도록 설정되어 있지만 로그인 기능이 없으므로 표시된 학과 일정은 누구나 볼 수 있습니다.

## 최초 배포 절차 — 캘린더 소유자

1. 캘린더 소유 Google 계정으로 https://script.google.com/ 에서 새 프로젝트를 만듭니다.
2. 저장소의 apps-script/department-calendar.gs 내용을 Code.gs에 복사하고 저장합니다.
3. 프로젝트 시간대를 Asia/Seoul로 지정합니다. 필요하면 manifest(appsscript.json)를 표시하고 저장소의 앱 스크립트 매니페스트를 반영합니다.
4. 배포 → 새 배포 → 유형 '웹 앱' 선택. 실행 사용자 '나', 액세스 권한 '모든 사용자(Anyone)'로 지정합니다.
5. Google 계정에서 캘린더 읽기 전용 권한을 승인합니다. 이는 ChatGPT 커넥터 연결과 별개의 동의입니다.
6. 만들어진 https://script.google.com/macros/s/.../exec 웹 앱 URL을 복사합니다.
7. 저장소 js/schedule-config.js에서 SCHEDULE_FEED_URL의 빈 문자열을 웹 앱 URL로 교체하고 커밋합니다.
8. GitHub Pages 배포 후 포털의 '학과 주요 일정'에 접속하여 공개 일정을 확인합니다.

**주의:** ChatGPT에서 연결된 Google Calendar 접근 권한을 외부 웹 사이트가 자동 승계하지 않습니다. 최초 웹 앱 배포는 소유자가 진행해야 합니다.

## 학과 일정 등록 형식

- (학과) 수시2차 면접 → 행사
- (학과) [시험] 중간고사 → 시험
- (학과) [프로젝트] 졸업작품 발표 → 프로젝트
- 지정 가능한 분류: [학사], [시험], [프로젝트], [취업], [자격증], [행사]
- 분류를 지정하지 않으면 행사로 표시합니다.
- 공개하지 않을 일정에는 (학과)를 붙이지 마세요. 공개 대상이라도 Private으로 지정하면 제외됩니다.
- 반복/종일/여러 날짜에 걸친 일정도 처리합니다. 종료일은 실제 마지막 일정 날짜로 표시됩니다.
- 일정 제목에 학생 개인정보나 민감 정보를 작성하지 마세요.

## 동기화 동작 및 확인

- 페이지 최초 로딩 및 달력 조회 월이 연동 범위를 벗어났을 때 새로 요청합니다.
- 페이지가 열려 있는 동안에는 5분마다 최신 공개 일정을 조회합니다. Apps Script 캐시도 최대 5분이므로 수정 시 반영 지연이 생길 수 있습니다.
- 조회 범위는 선택한 월 기준 전월부터 이후 약 9개월이며, 서버는 최대 366일 조회를 허용합니다.
- 로딩 실패 시 이전 데이터가 있으면 유지하고 오류 문구를 보여줍니다.
- 운영 확인: '(학과)' 없는 개인 일정은 미공개 / '(학과)' 일정만 공개 / Private은 제외 / 시간과 종일 종료일 정확성 / 수정·삭제 반영 / 모바일 달력 및 필터 확인.
- 서버 로직을 수정했다면 Apps Script '배포 관리'에서 기존 웹 앱 배포를 새 버전으로 업데이트해야 합니다.
- 배포를 중지하려면 js/schedule-config.js의 URL을 빈 문자열로 되돌리거나 웹 앱 배포를 비활성화하면 됩니다.

## 안전 설계

- 브라우저와 GitHub 저장소에 캘린더 OAuth 토큰, 비밀번호, 개인 캘린더 원본 데이터를 저장하지 않습니다.
- Apps Script가 캘린더를 개인 계정 권한으로 읽고 서버에서 접두어 및 Private 여부를 검사합니다.
- JSONP는 공개 정보만 응답할 때 사용합니다. 스크립트 콜백 이름을 허용된 형식으로 제한합니다.
- 서버 출력에는 최소 공개 필드만 포함하며 script 삽입에 사용될 수 있는 문자열은 이스케이프합니다.
