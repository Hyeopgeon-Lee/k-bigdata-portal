# 포털 GA4 접속 통계 설정

운영 대상: https://portal.k-bigdata.kr/ (그 외 서브도메인은 제외)

## 1. 현재 활성화 구성

- GA4 속성: K-Bigdata 학생용 포털
- 웹 스트림: K-Bigdata 학생 포털
- 사이트: https://portal.k-bigdata.kr/
- 측정 ID: `G-8PMMKFNRY7`
- 공통 태그: `js/analytics.js`; 모든 9개 HTML 페이지에 로드
- 모든 이벤트(`page_view`, `portal_navigation`, `portal_service_open`)의 `send_to`를 `G-8PMMKFNRY7`로 명시해 기존 입시·홍보용 GA4와 데이터 경로를 분리합니다.
- 기존 입시·홍보용 GA4 속성과 별도 운영

## 2. GA4 관리자 확인

1. https://analytics.google.com/ 에서 **K-Bigdata 학생용 포털** 속성을 선택합니다.
2. 관리 > 데이터 스트림에서 `https://portal.k-bigdata.kr/` 웹 스트림의 측정 ID가 `G-8PMMKFNRY7`인지 확인합니다.
3. 웹 스트림의 **향상된 측정**은 **사용 중지** 상태를 유지합니다.
4. GitHub Pages 배포 후 포털을 직접 열고 GA4의 **실시간 보고서**로 수집을 확인합니다.

**운영:** 측정 ID가 코드에 적용되었습니다. GitHub Pages 배포와 클라이언트 캐시 갱신 후 수집을 시작합니다. GA4 측정 ID는 공개 식별자이며 인증 토큰이나 비밀번호가 아닙니다.

## 3. 반영된 측정 범위

| 항목 | 측정 방식 | 분석 위치 |
| --- | --- | --- |
| 페이지 조회 | 모든 9개 HTML 페이지에서 `page_view` 1회 전송 | 보고서 > 참여도 > 페이지 및 화면 |
| 메인/직무/자격증/문제풀이/기술면접/자기소개서/공식문서/채용공고/프로젝트 가이드 | 안전한 페이지 경로로 구분 | 페이지 및 화면 |
| 포털 내 다른 페이지 이동 | `portal_navigation` / `destination_page` | 참여도 > 이벤트, 탐색 |
| 다른 학과 서비스로 이동 | `portal_service_open` / `destination_service` | 참여도 > 이벤트, 탐색 |
| 일별 방문 추이·활성 사용자·기기 유형 | GA4 기본 집계 | 보고서 및 탐색 |

`destination_page`와 `destination_service`별 세부 리포트를 보려면 **관리 > 맞춤 정의 > 맞춤 측정기준 만들기**에서 각각 이벤트 범위의 맞춤 측정기준으로 등록합니다. 등록 이후의 데이터부터 측정기준에 표시될 수 있습니다.

## 4. 개인정보 수집 최소화

- 측정 이벤트에 이름, 학번, 이메일, 학생 식별자, 폼 값, 검색어, 문제 답안은 추가하지 않습니다.
- URL의 **쿼리스트링**(`?id=...`, `?exam=...`) 및 **해시**(`#...`)는 제외하고, 정적 파일 경로만 수집합니다.
- 외부에서 유입된 리퍼러는 도메인 원점(origin)만 보존합니다. 페이지 내 검색 파라미터나 식별자는 수집하지 않습니다.
- Google Signals 및 광고 개인화 신호 사용을 코드 수준에서 비활성화합니다.
- 포털 링크 분석은 `apply`, `ready`, `room`, `help`, `alumni`, `ai`, `prof` 등 사전에 승인한 서브도메인의 서비스 이름만 집계합니다.
- GA4 자체의 기본 자동 수집 항목과 쿠키 동작은 GA4 관리 화면 설정에 따릅니다. 실제 활성화 전에 개인정보 처리방침의 분석 도구 이용 고지, 적정한 수집·보존 기간 및 필요한 동의 절차를 점검해야 합니다.
- GA4 웹 스트림의 **향상된 측정(Enhanced measurement)을 비활성화**하여 페이지 기록 변경, 사이트 검색, 외부 링크 클릭, 양식 상호작용 등이 원본 URL·값과 함께 자동 전송되지 않도록 합니다. 이 포털은 개인정보를 제외한 `page_view`, `portal_navigation`, `portal_service_open` 이벤트를 별도로 전송합니다.
- 공개 저장소에 GA 관리자 계정 비밀번호, 서비스 계정 키 또는 API 비밀키를 저장하지 않습니다.

## 5. 유의 사항

- `noindex, nofollow`는 검색 노출 억제용이며 접속 통제/인증 기능이 아닙니다. 내부 포털을 학생만 사용하도록 제한하려면 별도의 인증이 필요합니다.
- 추적 차단 확장 프로그램, 브라우저 보안 설정, 동의 여부 등에 따라 GA4 방문 통계는 실제 전체 사용자 수와 다를 수 있습니다.
- 이벤트 클릭은 이동 **시도**를 집계하는 것이며, 외부 서비스의 로그인 성공·예약·지원 완료를 의미하지 않습니다.
- 모든 9개 페이지의 태그 연결과 개인정보 제외 동작은 `node --test tests/analytics.test.mjs`로 확인할 수 있습니다.
