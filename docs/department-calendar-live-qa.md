# 학과 Google 캘린더 운영 검증

검증일: 2026-10-19, Asia/Seoul.

## 구축 및 보안

- 기존 개인 계정의 기본 캘린더 사용. 별도 캘린더를 생성하지 않음.
- 소유자가 Google OAuth 권한을 직접 승인함. 스크립트의 캘린더 권한은 읽기 전용.
- Apps Script 전용 프로젝트 생성, 비공개 Sheets 자동 생성, 웹 앱 소유자 실행 및 익명 조회 배포.
- Drive 권한 메타데이터: `shared=false`, 소유자 권한 1개. 공개/도메인 공유 없음.
- Sheets 및 스크립트 시간대: Asia/Seoul.
- `syncDepartmentCalendar` 시간 기반 트리거 1개, 10분 간격. 실행 이력의 시간 기반 실행 성공 확인(20:39:43, 20:44:01).
- 공개 API 응답에서 메모, 장소, 이메일, 회의 링크, 원본 캘린더 식별자 없음 확인.
- 저장소에는 공개 조회용 `/exec` URL만 등록. 비공개 저장소 ID 및 인증정보는 등록하지 않음.
- 저장소 Code.gs 원문을 편집기에 재적용하고 정규화한 내용 길이 및 체크섬을 읽기 확인한 뒤 기존 배포를 버전 2로 갱신. URL 유지.

## 운영 범위

- 공개하려는 일정은 기본 캘린더에 정확히 `(학과)`로 시작하도록 작성한다.
- 비공개/기밀로 지정한 일정은 접두어가 있어도 공개하지 않는다.
- 현재 월 기준 6개월 전부터 18개월 후까지 동기화한다.
- 서버 동기화는 약 10분 간격이며, 열려 있는 포털도 10분 간격으로 다시 조회한다. 새로고침하면 최신 동기화 결과를 바로 조회한다.
- 원본 Sheets와 Apps Script 프로젝트를 학생에게 공유할 필요가 없다.
