실기 코딩·SQL 문제은행

기출은 눈으로 읽는 것이 아니라 직접 손으로 풀어야 합니다.

종이와 펜을 준비하세요.

코드를 실행하거나 정답을 바로 확인하지 말고 변수 값과 실행 흐름을 종이에 직접 적어보세요.

문제 확인 → 종이 풀이 → 60초 고민 → 내 답 제출 → 단계별 풀이 → 오답 복습

풀이 이력과 입력 답은 이 브라우저에만 저장됩니다. 로그인·이름·학번 수집 및 서버 전송은 없습니다. 공용 기기에서는 학습현황의 ‘내 학습기록 삭제’를 사용하세요. 브라우저 데이터 삭제 시 기록도 사라집니다.

문제 데이터를 불러오고 있습니다.

비공식 복원기출 안내

본 문제은행의 기출문제는 공개된 응시자 복원자료와 학습자료를 교차 검토하여 정리한 비공식 복원기출입니다. 실제 시험 문제와 코드의 변수명, 수치, 표현 등이 일부 다를 수 있습니다.

‘기출 기반 변형’과 ‘추가 연습문제’는 실제 출제된 문제로 취급하지 않습니다. 출제 횟수는 확인한 이력만 집계하며, 오답률은 이 기기의 개인 학습기록 기준입니다. 자동 채점은 연습용이며 공식 시험 채점과 다릅니다.
