## 제한 및 후속 확인

실물 Android Chrome/iOS Safari, 가상 키보드 및 safe-area는 실기기 검증하지 않았다. visualViewport와 safe-area 대응은 구현했지만 실기기 보장을 주장하지 않는다. 포털 도메인의 기존 브라우저 접근 제한 때문에 운영 화면 직접 검수는 수행하지 않고 로컬 동일 파일로 검수했다. 배포 결과는 GitHub Pages 실행 결과로 별도 확인한다.

Service Worker는 공통 모듈 의존성과 데이터 업데이트/구버전 캐시 위험을 고려해 이번 UX 개편에서 도입하지 않았다. 오프라인 사용을 보장하지 않는다. 신규 문제 검수나 정답 대량 변경은 이번 작업 범위가 아니며 데이터 오류를 수정했다고 주장하지 않는다.
