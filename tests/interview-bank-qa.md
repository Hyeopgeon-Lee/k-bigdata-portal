- 150문제 전체 표시, 초기 답변 모두 닫힘. 답변 펼침/숨김과 꼬리질문 확인.
- JWT 검색, DevOps 직무, Docker·Kubernetes 분야와 한글 검색 확인.
- 랜덤 1문제와 10문제 순차 진행, 다음 문제의 답변 초기화, 완료·재시작·전체 복귀 확인.
- 잘못된 id 안내 후 전체 목록 표시. 기존 Kubernetes 분야 query 링크 유지.
- 360×800, 390×844, 412×915, 768×1024, 1024×768, 1440×900, 1920×1080에서 150개 카드·헤더·푸터 영역이 화면 폭을 넘지 않음.

## 출처 및 배포 확인 범위

- 공식 검수 링크는 data/interview-sources.js에서 관리. 자동 검사에서 Docker 상위 문서의 404를 발견하고 실제 컨테이너 문서 주소로 수정.
- 수정 후 공식 문서 33개와 주제 참고 자료 3개를 재확인하여 모두 HTTP 200 응답 확인(리다이렉트 후 최종 응답 기준).
- 공식 문서로 개념 검증, 공개 면접 정리 저장소와 기업 글은 주제 선정 참고로만 사용.
- 운영 도메인 직접 브라우저 검수는 기존 사용자 접근 제한을 존중해 수행하지 않음. 로컬 화면 QA와 GitHub Pages 배포 작업 결과는 별도로 확인.
- 정적 브라우저 검수는 실제 휴대폰·통신환경 검수를 완전히 대체하지 않음. 공식 문서와 기술 정책 변경 시 재검수 권장.
