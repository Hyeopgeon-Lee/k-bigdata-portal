GET STARTED

설치 및 사용 방법

  1. 01

    확장 프로그램 설치

    PC Chrome에서 웹 스토어를 열고 ‘Chrome에 추가’를 선택하세요. 확장 프로그램 메뉴에서 K-BigData Hub를 찾아 실행합니다.

  2. 02

    GitHub 저장소와 토큰 준비

    내 GitHub 계정에 학습용 저장소를 만들고, 해당 저장소에만 접근할 수 있는 토큰을 준비합니다. 가능하면 만료일을 지정한 Fine-grained token을 사용하고 필요한 Contents 읽기·쓰기 권한만 허용하세요.

    GitHub 토큰 설정 ↗
  3. 03

    K-BigData Hub 설정

    확장 프로그램 설정 창에 GitHub 토큰을 입력하고 저장소, 브랜치(필요한 경우), 폴더를 설정한 뒤 저장합니다. ‘올리기 전에 물어보기’는 켜 두기를 권장합니다.

    ‘문제도 함께 올리기’는 끄고 자신이 직접 작성한 풀이 코드만 등록하세요.

  4. 04

    코딩 문제 풀이 및 등록

    학과 포털의 기초 코딩 350제에서 내 답안을 작성하고 정답·해설을 확인합니다. ‘맞혔어요’를 누른 후 파일 이름과 저장 위치를 확인하고 ‘올리기’를 선택하세요.

    기초 코딩 350제 바로가기 →
  5. 05

    GitHub에서 확인

    지정한 저장소의 브랜치와 폴더를 열어 등록된 소스코드를 확인합니다. 꾸준히 본인의 학습 기록을 쌓아 보세요.

SECURITY

사용 시 주의사항

  • GitHub 토큰은 비밀번호와 같습니다. 타인과 공유하거나 코드·README·화면 캡처에 노출하지 마세요.
  • 권한을 필요한 저장소에만 부여하고, 공용 PC에서는 토큰을 저장하지 마세요. 노출이 의심되면 GitHub에서 즉시 폐기하세요.
  • 공개 저장소에는 직접 작성한 코드만 올리세요. 문제 원문, 해설, 스캔 자료 및 개인정보는 등록하지 마세요.

FAQ

자주 묻는 질문

확장 프로그램을 설치했는데 동작하지 않아요.

PC Chrome에서 확장 프로그램이 활성화되어 있는지 확인하고, 학과 포털의 기초 코딩 페이지를 새로고침해 보세요.

GitHub에 저장되지 않아요.

토큰의 유효기간, 저장소 이름, 접근 권한, 브랜치 설정을 확인하세요. 토큰은 다른 사람에게 전달하지 마세요.

확장 프로그램을 설치하지 않아도 코딩 문제를 풀 수 있나요?

네. 확장 프로그램은 선택 사항이며, 기존 포털의 문제 풀이 기능은 그대로 사용할 수 있습니다.
