## 출처와 표시

첨부 자료의 기본 문제도 코드·수치를 새로 구성한 학습용 자료입니다. 회차 258개 모두 미검증이며, 출처 링크가 있다는 사실만으로 문항·연도 일치 또는 복원 신뢰도 B를 인정하지 않습니다. 신규 자료에는 실제 출제 이력 및 복원 신뢰도를 부여하지 않았습니다. 시험 필터의 연결은 권장 학습 대상이며 실제 출제 증명이 아닙니다.

- `normalized`: 공개 복원자료 기반 정규화
- `transformed`: 기출 기반 변형
- 기존 `reconstructed`: 비공식 복원기출 (별도 검증 자료)

복원기출 기본 필터는 유지합니다. 신규 자료는 문제 종류 필터의 정규화/변형 또는 전체 종류에서 확인합니다. 정확한 출제 횟수는 기존 검증된 이력 18건만 집계합니다.

Python 62개 원 레코드는 격리 Python 실행 결과와 비교하여 모두 일치했습니다. 정답의 문자형 `\\n`을 실제 줄바꿈으로 변환했습니다. C/Java는 32개 개념 템플릿의 코드 흐름을 읽어 확인했지만 로컬 컴파일러가 없어 전체 코드 컴파일·실행 검증은 완료하지 않았습니다. SQL은 표현의 동등성을 자동 판단하지 않으며 답안 비교 후 자기 판정을 사용합니다. 출처 페이지와 각 문항의 일대일 일치는 검증되지 않았습니다.
